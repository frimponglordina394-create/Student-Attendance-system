# Digital Attendance System

A simple console-based C++ program for managing student attendance in lectures.

Developed as a mid-semester capstone project for **EEE227 – Introduction to C++ Programming** (HND Electrical Engineering, Level 200).
** Name **:OSAM-FRIMPONG LORDINA
**Index number**:01243413D
## Features
- Register new students (index number + name)
- View all registered students
- Search student by index number
- Create a lecture session (course code, date, time)
- Mark attendance (Present 'P', Absent 'A', Late 'L')
- View current session attendance list + summary (P/A/L counts)
- Students saved in `students.txt`
- Sessions saved in `sessions/` folder (one file per session)
